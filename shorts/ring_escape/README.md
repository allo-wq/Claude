# RING ESCAPE: Orange vs Blue

A 49-second vertical short (1080×1920, 60 fps, with sound) for the **Loop Lab** channel, built to loop and get comments.
The physics, visuals and soundtrack are all generated by code.

**▶ [`ring_escape_short.mp4`](ring_escape_short.mp4)**, cover frame: [`cover.png`](cover.png)

## What happens

Two balls bounce inside 21 neon rings that spin in a slowly twisting spiral. Each ring has a gap.
When a ball slips through the gap of the innermost ring, that ring shatters and the ball scores.

- **Hook (0–1 s):** the scoreboard and "PICK A SIDE IN THE COMMENTS" are up from frame 1, and the first ring breaks at 0.9 s.
- **Satisfying beats:** a 4-ring chain reaction at ~5 s, plus shards, shockwaves, screen shake and "+1"/"+2" popups.
- **Sound:** every bounce plays the next note of *In the Hall of the Mountain King*
  (Grieg, 1875, public domain), so the melody speeds up with the action. Each shattered ring
  plays a chime one semitone higher than the last, so the pitch keeps climbing.
- **Drama:** a crown follows the leader through **5 lead changes**. Blue comes back from 0–3 down,
  and it's **10–10 going into the final ring**. A heartbeat plays, then slow motion, then the last ring breaks.
- **Payoff + loop:** the screen reads "BLUE WINS! 10–11" and "DID YOU CALL IT?" with confetti, then the
  Loop Lab end card appears and the video loops back to "PICK A SIDE…", which invites a rewatch.

The race isn't scripted: it's a real simulation. `render.py search` simulated 3,000 random seeds and
ranked them by drama (tied before the last ring, lead changes, comeback size, length). Seed 2129 came out near the top.

## Re-render / make a new episode

Requires Python 3, `numpy`, `pillow`, `pycairo` (`pip install pycairo`) and `ffmpeg`.

```bash
python3 render.py search                          # rank 3000 seeds by drama
python3 render.py still --times 0,5.12,final,end  # preview PNGs
python3 render.py render --seed 2129              # full MP4 (~2 min on 4 cores)
python3 render.py audio                           # rebuild only the soundtrack
```

Each new seed is a new race and a new episode. Swapping `BALL_COL`/`BALL_NAME` in `render.py`
turns it into a different matchup, such as two countries, teams or brands, for a series.

| File | What it does |
|---|---|
| `sim.py` | Deterministic physics: gravity, elastic bounces, rotating gaps, ring breaking, scoring |
| `render.py` | Seed search, cairo renderer with bloom, slow-mo time remap, synthesized audio, ffmpeg encode |
| `../brand.py` | The shared Loop Lab end card and chime, used by every video |

## Channel outro

The end card lives in [`../brand.py`](../brand.py) and doesn't depend on this video, so every
future Loop Lab video can end the same way:

```python
import brand
brand.draw_card(ctx, cx, cy, t)   # t = seconds since the card appeared
brand.sting(48000)                # matching two-note chime
```

Run `python3 ../brand.py` to write a preview PNG. Change `NAME` or `TAGLINE` there to update it everywhere.

Audio is mastered to about −14 LUFS (YouTube's loudness target) with a −1.5 dBTP ceiling.
